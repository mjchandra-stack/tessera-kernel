# Per-architecture clippy findings, recorded rather than fixed (D183). The
# aspects that lint the rest of the graph cannot cross the platform transition,
# so these are what `--config=lint-<arch>` reports for the ports and kernel
# binaries — code that had never been linted at all until D183 found it.
#
# The number may fall, and should. It may rise only for the one class of
# finding that cannot be taken: `deref_addrof` on `(*(&raw mut STATIC))`, where
# clippy's suggested fix is to name the `static mut` directly and edition 2024
# forbids exactly that. A new module that reaches a kernel static adds one such
# finding per access point, and the answer is to funnel those through one
# helper — not to leave them scattered and not to pretend the count held.
#
# Any other rise is a regression: `tools/ci/arch-lint.sh` fails on growth,
# which is the discipline unsafe-inventory.toml already applies to a list that
# must shrink and never silently grow. A raise here without a ledger entry
# saying which findings and why is the thing this file exists to prevent.
#
# When a count reaches zero, drop the line — an architecture with no findings
# should fail on the first one rather than tolerate a budget of nothing.
#
# x86_64 169 -> 171 (D249): the root task's syscall handler reaches this port's
# process and object tables, which is two more `deref_addrof` sites. Eight
# before they were funnelled — one per call site across `DebugWrite`,
# `ProcessCreate`, `AddressSpaceMap` and `ProcessStart` — and two after, which
# is `root_processes()` and `root_objects()`. Both are the sanctioned class:
# clippy's fix is to name the `static mut` directly and edition 2024 forbids
# it. The pair goes when the loader trio moves into `kcore::dispatch`, which
# takes its tables as arguments and reaches no static at all.
#
# x86_64 171 -> 166 (D250): the three component-manager demos went, and five
# findings went with them. Nothing was fixed to get here — a count falls
# because code a check no longer needs stopped existing, which is the direction
# this file is supposed to move.
